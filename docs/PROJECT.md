# 프로젝트 정의

## 프로젝트명

「えらべる！」

## 목적

「えらべる！」은 선택지가 많아서 결정을 내리기 어려울 때,
사용자를 대신해서 선택지 중 하나를 랜덤으로 골라주는
아주 간단한 캐주얼 웹앱이다.

사용자는 자신이 결정해야 할 선택지를 직접 추가하고,
「えらぶ」 버튼을 누르면 등록된 선택지 중 하나가 선택된다.

복잡한 설정이나 설명 없이 빠르게 사용할 수 있는 것을 목표로 한다.

## 대상 사용자

일본어를 사용하는 일반 사용자.

특정 연령이나 전문 지식을 요구하지 않으며,
누구나 처음 방문했을 때 사용 방법을 직관적으로 이해할 수 있어야 한다.

## 서비스 지역

일본 내 배포를 기본으로 한다.

## 서비스 언어

사용자에게 제공되는 UI, 버튼, 안내 문구, 에러 메시지 등은
일본어를 기본 언어로 한다.

개발 문서의 언어와 사용자에게 제공되는 서비스 언어는 구분한다.

## 제품 철학

- 고민할 때 바로 사용할 수 있어야 한다.
- 가능한 한 조작 횟수를 줄인다.
- 설명을 읽지 않아도 사용 방법을 알 수 있어야 한다.
- 캐주얼하고 친근한 분위기를 유지한다.
- 조금 재미있고 가벼운 느낌을 준다.
- 기능을 작게 시작하고 지속적으로 개선한다.
- 필요 이상의 기능이나 복잡한 구조를 추가하지 않는다.
- 핵심 가치인 "하나를 빠르게 결정해준다"를 최우선으로 한다.

## 핵심 사용자 흐름

기본적인 사용자 흐름은 다음과 같다.

1. 사용자가 선택지를 입력한다.
2. 선택지를 추가한다.
3. 필요하지 않은 선택지를 삭제한다.
4. 「選ぶ」 버튼을 누른다.
5. 등록된 선택지 중 하나를 랜덤으로 선택한다.
6. 선택 결과를 명확하게 표시한다.

이 과정은 가능한 한 적은 조작으로 완료할 수 있어야 한다.

## 현재 기능

MVP에서는 다음 기능을 제공한다.

- 선택지 추가
- 선택지 삭제
- 랜덤 선택
- 선택 결과 표시
- 선택지가 없는 경우의 적절한 안내
- 선택지가 하나뿐인 경우의 적절한 처리

## MVP 범위

MVP는 브라우저에서 동작하는 간단한 웹앱으로 구현한다.

다음 기능은 MVP의 필수 범위에 포함하지 않는다.

- 백엔드
- 데이터베이스
- 사용자 인증
- 사용자 계정
- 외부 API
- 복잡한 상태 관리 라이브러리

기능상 명확한 필요성이 발생하기 전까지
프로젝트를 위와 같은 구조로 확장하지 않는다.

## 향후 기능 후보

향후 다음 기능을 검토할 수 있다.

- 선택지 프리셋
- LocalStorage를 이용한 선택지 저장
- 선택 기록
- 선택 결과 공유
- 광고
- 다국어 지원

위 기능들은 현재 MVP의 요구사항이 아니다.

새로운 기능을 추가할 때는 현재 앱의 단순함과
사용 편의성을 해치지 않는지 먼저 검토한다.

## 범위에 포함하지 않는 것

이 프로젝트는 다음과 같은 서비스가 되는 것을 목표로 하지 않는다.

- 고기능 작업 관리 앱
- 본격적인 의사결정 지원 시스템
- SNS
- 복잡한 사용자 계정 시스템
- 과도한 사용자 맞춤 설정
- 복잡한 데이터 분석 시스템

이 프로젝트의 핵심 가치는
"결정하기 어려울 때 빠르게 하나를 골라준다"는 것이다.
