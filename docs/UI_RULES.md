# UI 규칙

## 디자인 방향

앱 전체가 다음과 같은 느낌을 가져야 한다.

- 캐주얼
- 친근함
- 따뜻함
- 단순함
- 약간의 재미
- 가볍게 사용할 수 있는 느낌

사용자가 처음 방문했을 때
"어떻게 사용하는 거지?"라고 생각하지 않도록
직관적인 UI를 만든다.

## 피해야 할 디자인

다음과 같은 디자인은 피한다.

- 기업용 서비스처럼 딱딱한 UI
- 지나치게 기술적인 UI
- 정보가 지나치게 많은 레이아웃
- 과도한 그라데이션
- 과도한 애니메이션
- 지나치게 많은 장식
- 복잡한 조작 과정
- 장식을 위해 사용성을 희생하는 디자인

## 브랜드 느낌

「えらべる！」이라는 이름에 어울리는
밝고 친근한 디자인을 기본으로 한다.

사용자가 결정을 고민하고 있는 상황에서도
부담이나 스트레스를 느끼지 않고 사용할 수 있어야 한다.

앱의 분위기는 진지한 의사결정 도구보다는
가볍게 "이걸로 하자!"라고 결정할 수 있도록 도와주는
캐주얼한 서비스에 가깝게 만든다.

## 색상

주요 강조 색상:

- Coral

배경:

- Warm Cream

텍스트:

- Dark Green-Gray

보조 Surface:

- Mint

이미 프로젝트에 정의된 CSS Variables가 있다면
가능한 한 기존 Variables를 재사용한다.

동일한 용도의 색상을 새롭게 추가하지 않는다.

새로운 색상이 정말 필요한 경우에는
기존 색상 체계와 조화를 이루는지 먼저 확인한다.

## 타이포그래피

일본어 텍스트의 가독성을 최우선으로 한다.

중요한 결정 메시지와 선택 결과는
충분히 큰 글자로 표시한다.

너무 많은 Font Weight를 사용하지 않는다.

제목, 본문, 보조 정보 등의 중요도가
시각적으로 자연스럽게 구분되도록 한다.

## 사용자 언어

사용자에게 표시되는 모든 텍스트는 기본적으로 일본어를 사용한다.

다음 요소를 포함한다.

- 제목
- 버튼
- Placeholder
- 안내 문구
- 에러 메시지
- 빈 상태 메시지
- 선택 결과 메시지

사용자에게 표시되는 일본어는
자연스럽고 친근한 표현을 우선한다.

지나치게 딱딱한 경어와 기술적인 표현은 피한다.

버튼과 안내 문구는 짧고 직관적으로 작성한다.

## 컴포넌트

인터랙티브한 UI에는 Material Web Components를 사용한다.

우선적으로 사용하는 컴포넌트:

- `md-outlined-text-field`
- `md-filled-button`
- `md-outlined-button`
- `md-icon-button`

이미 존재하는 Material Web Component로 구현할 수 있다면
새로운 UI 컴포넌트를 만들지 않는다.

다른 UI Component Library를 추가하지 않는다.

## 레이아웃

레이아웃에는 Tailwind CSS를 우선적으로 사용한다.

다음 요소는 Tailwind CSS를 이용해 관리한다.

- Layout
- Spacing
- Width
- Height
- Alignment
- Responsive Behavior

동일한 스타일을 여러 곳에서 반복하게 되는 경우에는
기존 CSS Variables 또는 공통 스타일을 검토한다.

## 반응형 디자인

앱은 다음 환경에서 정상적으로 사용할 수 있어야 한다.

- Desktop
- Tablet
- Mobile

특히 Mobile 환경을 중요하게 고려한다.

약 360px 너비의 화면에서도
주요 기능을 문제없이 사용할 수 있어야 한다.

기본적으로 가로 스크롤이 발생하지 않도록 한다.

## 인터랙션

주요 기능의 조작 횟수를 최소화한다.

사용자가 다음에 무엇을 해야 하는지
별도의 설명 없이 이해할 수 있도록 한다.

특히 「選ぶ」 기능은 이 앱의 핵심 기능이므로
시각적으로 명확하게 강조한다.

## 선택 결과

랜덤으로 선택된 결과는
사용자가 한눈에 알아볼 수 있도록 표시한다.

선택 결과는 화면에서 가장 중요한 정보 중 하나로 취급한다.

필요한 경우 일반적인 선택지보다

- 더 큰 Typography
- 충분한 여백
- 명확한 시각적 강조

를 사용한다.

단, 과도한 애니메이션이나 장식은 사용하지 않는다.

## 접근성

다음 사항을 기본적으로 지킨다.

- 버튼과 입력 요소를 키보드로 조작할 수 있어야 한다.
- 텍스트와 배경 사이에 충분한 대비를 확보한다.
- Icon만으로 의미를 전달하는 경우 적절한 Accessible Name을 제공한다.
- 터치 가능한 요소는 충분한 크기를 확보한다.
- 색상만으로 상태나 의미를 전달하지 않는다.
- Focus 상태가 필요한 인터랙티브 요소에는 적절한 시각적 표시를 제공한다.

## 애니메이션

애니메이션은 사용자 경험을 향상시키는 보조적인 목적으로만 사용한다.

선택 결과를 보여줄 때와 같이
사용자 경험에 실제로 도움이 되는 경우에만 사용한다.

다음은 피한다.

- 지나치게 긴 애니메이션
- 사용자의 조작을 지연시키는 애니메이션
- 반복적으로 시선을 방해하는 애니메이션
- 단순한 장식을 위한 과도한 애니메이션

## 일관성

같은 종류의 UI에는 동일한 디자인 규칙을 적용한다.

기존 디자인을 확인하지 않고
새로운 UI 패턴을 임의로 만들지 않는다.

새로운 UI를 추가할 경우 기존의

- Color
- Typography
- Spacing
- Component
- Interaction

과 일관성을 유지한다.
